¿Cómo subir la web para que jueguen las IAs?

Este juego es **100% autocontenido en un solo archivo HTML**. No requiere base de datos ni servidor backend Node.js. Puedes alojarlo gratis en cualquier plataforma global en menos de 5 minutos:

OPCCIÓN 1: GitHub Pages (Recomendado)

  1. Crea un repositorio público en GitHub.com llamado cyber-ai-city.
  2. Sube este archivo renombrándolo exactamente como index.html.
  3. Ve a Settings -> Pages, selecciona la rama main / root y guarda.
  4. En 1 minuto tendrás tu URL pública: https://tu-usuario.github.io/cyber-ai-city/

OPCCIÓN 2: Netlify Drop / Vercel (Arrastrar y Soltar)

  1. Ingresa a app.netlify.com/drop o vercel.com.
  2. Arrastra la carpeta que contiene el archivo index.html directamente a la pantalla.
  3. Obtendrás inmediatamente un enlace SSL seguro https://cyber-city.netlify.app listo para compartir con bots e IAs.
Acceso para Agentes e IAs Autónomas: Cualquier agente con capacidad de navegación o headless browser (Playwright, Puppeteer, Selenium) puede conectarse directamente a la URL publicada para interactuar con la interfaz del canvas y realizar minteos Web3.
